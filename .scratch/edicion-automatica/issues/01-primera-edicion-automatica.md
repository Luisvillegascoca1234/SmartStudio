# 01 — Mostrar la primera edición automática de la fotografía principal

**What to build:** un primer recorrido completo y visible donde finalizar una sesión fotográfica crea un trabajo para la fotografía principal, produce una edición local sencilla, permite comparar antes y después y registra la aprobación del operador.

**Blocked by:** None — can start immediately.

**Status:** completed

- [x] Finalizar una sesión fotográfica lista para edición crea automáticamente un único trabajo para su fotografía principal.
- [x] La interfaz muestra que el trabajo está en cola, procesando y listo para revisar.
- [x] El primer procesamiento aplica una transformación local real y determinista que permite observar una diferencia controlada.
- [x] El operador puede comparar claramente el original y la vista previa editada.
- [x] El operador puede aprobar la vista previa y la sesión fotográfica refleja esa decisión.
- [x] Los RAW y JPEG originales no se modifican durante el recorrido.
- [x] Una nueva sesión fotográfica puede iniciarse mientras la edición anterior está disponible para revisión.
- [x] El incremento no incorpora todavía revelado ARW, retoque facial, QR, impresión ni entrega.
- [x] Una verificación integral recorre el comportamiento desde la interfaz usando una captura controlada y comprueba resultados observables.
