# 08 — Añadir mejoras suaves de ojos y dientes

**What to build:** completar el perfil de retrato con corrección suave de ojos rojos, mejora ligera de brillo y nitidez de ojos y blanqueamiento dental moderado, manteniendo identidad y apariencia natural.

**Blocked by:** 07 — Añadir detección facial y suavizado de piel.

**Status:** completed

- [x] Los ojos rojos detectados se corrigen suavemente sin oscurecer ni recolorear ojos normales.
- [x] La mejora de ojos se limita a brillo y nitidez ligeros.
- [x] La función no cambia color del iris, tamaño o forma de ojos ni dirección de la mirada.
- [x] El blanqueamiento dental reduce dominantes amarillas moderadamente y conserva textura y color natural.
- [x] La función no produce dientes de blanco puro ni modifica su geometría.
- [x] Los tratamientos se aplican de manera coherente a los rostros detectados en fotografías grupales.
- [x] La detección incierta omite la modificación correspondiente y muestra una advertencia en lugar de adivinar.
- [x] Los efectos aparecen de forma consistente en vista previa, versiones y JPEG completo aprobado.
- [x] Ninguna mejora introduce reconocimiento de identidad, edición generativa o cambios corporales.
- [x] Las verificaciones automatizadas usan capturas controladas; cualquier juicio visual manual queda pendiente hasta que el usuario autorice QA.
