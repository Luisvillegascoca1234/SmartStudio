# 04 — Añadir selección asistida por calidad

**What to build:** ayudar al operador a revisar una serie mediante advertencias y ordenamiento de calidad, manteniendo siempre la selección bajo control humano y produciendo una principal inequívoca.

**Blocked by:** 03 — Hacer robusta la recepción e importación de capturas.

**Status:** completed

- [x] La revisión muestra miniaturas y una vista ampliada de las capturas de la serie.
- [x] La aplicación puede advertir desenfoque, movimiento, ojos cerrados, encuadre deficiente, exposición claramente incorrecta y archivos incompletos.
- [x] Las advertencias permiten destacar u ordenar candidatas sin ocultar las demás.
- [x] Ninguna advertencia selecciona, descarta, excluye o elimina automáticamente una fotografía.
- [x] El operador puede seleccionar como máximo tres fotografías.
- [x] Una selección lista para edición exige exactamente una fotografía principal.
- [x] El operador puede cambiar la principal sin perder las alternativas.
- [x] Las fotografías no seleccionadas y excluidas continúan conservadas.
- [x] La sesión muestra un estado inequívoco de lista para edición cuando cumple las reglas.
- [x] Las verificaciones incluyen fotografías controladas con distintos problemas y demuestran que la decisión final siempre pertenece al operador.
